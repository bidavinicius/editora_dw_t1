# editora_dw_t1

Trabalho 01 - Desenvolvimento Web - UEPG

API da Editora em Spring Boot

Alunos: Giulia Victoria Vante e Vinicius Ribas Bida.

## Para rodar

Copie `.env.example` para `.env` e preencha com as credenciais do seu banco. Depois rode:

```
set -a && source .env && set +a
```

```
mvn spring-boot:run
```

A API sobe em `http://localhost:8000/editora`.
